# Долина Тихого Звона

Браузерный платформер для практического задания 3: маг-картограф собирает три руны, получает три способности и пробивается через долину к древнему колоколу.

Игра написана на **SvelteKit 2 / Svelte 5 + TypeScript**, рисуется через **Canvas 2D**, собирается в статический сайт через **adapter-static**. Готовый билд не требует сервера и подходит для GitHub Pages.

## Тема и правила

- **Тема:** сбор артефактов, «Долина Тихого Звона».
- **Цель:** собрать руны **Пути**, **Огня** и **Лёгкости**, затем добраться до колокола в конце долины.
- **Опасности:** проклятый туман внизу, шесть стражей, проклятые шипы.
- **Уровень:** длинная долина на 7400 px с движущейся платформой, двумя прыжковыми площадками, ветряным потоком, двумя огненными галереями и широким разломом, который проходится рывком или планированием.
- **Прыжок:** только с опоры; двойного прыжка нет. Небольшие coyote-time и jump-buffer добавлены только для отзывчивости управления.
- **Сложность:** уровень проходится без случайного «идеального» прыжка. Способности дают запас по высоте и расстоянию, а огненные галереи требуют убить стражей.

### Руны и способности

| Руна | Способность | Управление | Как работает |
| --- | --- | --- | --- |
| **Путь** | Рывок с телепортацией | `Shift` / `E` | Мгновенный рывок вперёд до 300 px; перезарядка 2.4 с |
| **Огонь** | Пламя из посоха | `F` / `Q` | Конус огня перед магом убивает стражей; тряска камеры; перезарядка 1.15 с |
| **Лёгкость** | Медленное падение | пассивно | После получения руны падение ограничено безопасной скоростью |

Способности открываются по мере сбора рун. До получения руны слот способности заблокирован. Кулдауны видны в HUD на компьютере и через состояние экранных кнопок на телефоне.

### Очаги-чекпоинты

По долине расставлены **шесть очагов**. Маг зажигает очаг, просто коснувшись его: вспыхивает пламя, звучит колокольчик, а номер очага появляется в HUD рядом с рунами.

- После гибели появляется экран поражения с кнопкой **«Вернуться к очагу»** (`Enter` или `Space`). Маг возвращается к последнему зажжённому очагу, а собранные руны, способности, эхо, счёт и время сохраняются.
- Кнопка **«Заново»** (`R`) начинает поход с самого начала и гасит все очаги.
- Пока не зажжён ни один очаг, кнопки возврата нет — только полный перезапуск.
- Очаги не сбрасывают убитых стражей: если страж уже сожжён, он не возвращается.
- Таймер не останавливается на экране поражения, поэтому возврат к очагу не обнуляет время забега.

### Счёт и рекорд

| Событие | Очки |
| --- | ---: |
| Руна | +100 |
| Эхо-осколок | +50 |
| Финиш | +200 |
| Бонус за время | `max(0, 300 − floor(секунды × 3))` |

На уровне три обязательные руны и одиннадцать необязательных эхо-осколков. Лучший счёт и лучшее время сохраняются в `localStorage`. Лучшее время записывается только за победу; лучший счёт — после победы или поражения (по собранному за забег).

- `silent-toll-best-score`
- `silent-toll-best-time`
- `silent-toll-muted`

Если хранилище недоступно (приватный режим, запрет cookies), игра продолжает работать, а рекорд живёт только до перезагрузки.

## Управление

| Действие | Клавиатура | Телефон |
| --- | --- | --- |
| Движение | `←` `→` или `A` `D` | экранные кнопки «влево» / «вправо» |
| Прыжок | `Space`, `W` или `↑` | экранная кнопка «прыжок» |
| Рывок | `Shift` или `E` | экранная руна «Путь» |
| Пламя | `F` или `Q` | экранная руна «Огонь» |
| Лёгкость | пассивно | пассивно |
| Пауза / продолжить | `P` или `Esc` | кнопка паузы в шапке игры |
| Вернуться к очагу | `Enter` или `Space` на экране поражения | кнопка «Вернуться к очагу» |
| Заново | `R` | кнопка перезапуска в шапке игры |
| Звук | кнопка динамика | кнопка динамика |

Кнопки «Начать путь», «Пауза», «Продолжить», «Вернуться к очагу» и «Заново» есть в интерфейсе. При уходе со вкладки игра автоматически ставится на паузу; при возврате нужно нажать «Продолжить».

## Что реализовано

- Один игровой цикл через `requestAnimationFrame`: `update(dt)` → `render()`.
- `dt` считается по времени кадра и ограничивается 50 мс; после паузы время предыдущего кадра сбрасывается.
- Гравитация, ускорение, трение, ограничение скорости падения.
- Раздельное разрешение столкновений по осям с учётом предыдущей позиции — герой не проваливается сквозь платформы.
- **Рывок с телепортацией:** проверяет препятствия, переносит мага вперёд, даёт эффект и перезарядку.
- **Огонь:** конус пламени из посоха, убивает стражей, вызывает тряску камеры; отдельный звук и частицы.
- **Лёгкость:** пассивное медленное падение, голубая аура и перья; позволяет пересекать обрывы, непроходимые обычным прыжком.
- Движущаяся платформа с переносом игрока.
- Две прыжковые площадки: одна открывает путь к руне Огня, вторая — к финальному высокому участку.
- Ветряной поток, поднимающий героя к руне Лёгкости.
- Две огненные галереи с низким потолком и стражами: без пламени проход опасен.
- Шипы на земле у старта и на платформе с высоким эхо-осколком.
- Шесть стражей: два патрулируют платформы, четверо стерегут галереи; огонь убивает их.
- Три руны, одиннадцать эхо-осколков, счёт и обязательное условие финиша.
- Победа после сбора всех рун и входа в колокол; поражение от тумана, стража, шипов или падения.
- Шесть очагов-чекпоинтов: касание зажигает очаг, после гибели маг возвращается к последнему зажжённому, сохраняя руны, эхо, счёт и способности.
- Старт, пауза, продолжение, возврат к очагу и заново; после победы симуляция останавливается.
- Автопауза по `visibilitychange` и очистка зажатых клавиш.
- Рекорд в `localStorage` с обработкой ошибок хранения.
- Экранные кнопки для телефона с поддержкой удержания и мультитача.
- Синтезированные WebAudio-эффекты (прыжок, рывок, огонь, сбор, площадка, победа, поражение) и выключатель звука; внешних аудиофайлов нет.
- `prefers-reduced-motion`: меньше частиц, без покачиваний, тряски и вращений.
- Клавиатурная доступность, видимый фокус, `aria-live` для важных событий, подпись игрового поля.
- Адаптивная вёрстка: на телефоне кнопки находятся под игровым полем.

## Технологии

- SvelteKit 2 / Svelte 5
- TypeScript
- Canvas 2D
- `@sveltejs/adapter-static`
- Vite
- GitHub Actions + GitHub Pages

Игровой движок не используется. Логика разделена по модулям, как в задании про ванильный JS:

```text
src/lib/game/
  game.ts        — состояние, цикл, паузы, способности, очаги, победа/поражение, рекорд
  player.ts      — физика героя, прыжок, coyote-time, jump-buffer, лёгкость
  input.ts       — клавиатура, рывок, огонь и виртуальные кнопки
  collision.ts   — AABB, circle/rect, разрешение столкновений
  level.ts       — уровень, платформы, подъёмник, руны, шипы, ветер, стражи, очаги, колокол
  renderer.ts    — пейзаж, платформы, герой, огонь, лёгкость, очаги, частицы, колокол
  audio.ts       — WebAudio-синтез
  storage.ts     — безопасная работа с localStorage
  types.ts       — общие типы и константы
```

Компонент `src/lib/components/GameShell.svelte` отвечает за canvas, HUD, панель способностей, оверлеи, кнопки и фокус.

## Запуск

```bash
npm install
npm run dev
```

Проверка типов и сборка:

```bash
npm run check
npm run build
npm run preview
```

Сборка для GitHub Pages с базовым путём `/web-practice-3`:

```bash
npm run build:pages
npm run preview:pages
```

`preview:pages` поднимает локальный сервер по адресу `http://127.0.0.1:4173/web-practice-3/` — так проверяется именно тот путь, который будет на GitHub Pages. Если порт занят: `$env:PORT=4193; npm run preview:pages` в PowerShell или `PORT=4193 npm run preview:pages` в bash.

## Публикация на GitHub Pages

1. Репозиторий: `https://github.com/Ixniyevonn/web-practice-3`.
2. Ветка `main` — на неё настроен workflow.
3. В настройках репозитория: **Settings → Pages → Source → GitHub Actions**.
4. Workflow `.github/workflows/deploy.yml` соберёт сайт с `BASE_PATH=/web-practice-3` и опубликует папку `build`.
5. Адрес: `https://ixniyevonn.github.io/web-practice-3/`.

Если репозиторий будет называться иначе, поменяйте `BASE_PATH` в скрипте `build:pages` и в workflow.

## Ассеты и разрешения

- **Фон:** Nikita Shushman, «The Valley of Silent Toll» — [ArtStation](https://cdnb.artstation.com/p/assets/images/images/103/412/831/large/nikita-shushman-the-valley-of-silent-toll.jpg?1792601148). Изображение предоставлено автором проекта и перекодировано в WebP для веса страницы.
- **Руны Пути, Огня и Лёгкости, иллюстрация стража:** из личного проекта автора `gloat-svelte`, используются с разрешения автора. Огонь и Лёгкость — перекрашенные варианты рун автора. Подпись автора иллюстрации стража: **Monika Andruszkiewicz**.
- **Шрифты:** Book Antiqua, Nunito, JetBrains Mono — локальные woff2-файлы из проекта `practice1`.

Внешних звуковых файлов нет: все эффекты синтезируются через Web Audio API. Звук отключается кнопкой динамика; состояние выключателя сохраняется.
